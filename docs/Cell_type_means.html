Cell type means

Overview

This vignette demonstrates how chromosome arm mean expression profiles can be summarised across annotated cell populations. In this ovarian cancer dataset, epithelial and tumour-associated populations exhibit distinct chromosome arm level expression patterns compared with other cell types, highlighting the importance of reference selection for SCNA inference.

Comparison of cell means

Chromosome arm mean profiles were computed separately for each annotated cell population using compute_reference(). The resulting chromosome arm level mean expression values can then be compared across cell types.

# Compute references for each cell type
all_group_refs <- purrr::map_dfr(
  unique(xenium.obj$group),
  function(g) {
    compute_reference(
      xenium.obj,
      group_var= "group",
      group_names = g
    ) %>%
      mutate(group = g)
  }
)

Chromosome arm means for each cell type are shown below.

# Supplementary Figure 1: Mean chromosome arm-level gene expression across different cell types.
ggplot() +
  geom_vline(xintercept=hg38_chrom_info$cum_centromere_mid, linetype =  "dashed",linewidth = .3) +
  geom_vline(xintercept=hg38_chrom_info$cum_length,linewidth = .3) +
  geom_segment(
    data = all_group_refs %>% filter(arm == "p"),
    aes(x = p_start, xend = p_end, y = mean_arm_expr, 
        colour = group),
    linewidth = .8, linetype = "11") +
  geom_segment(data = all_group_refs %>% filter(arm == "q"),
    aes(x = q_start, xend = q_end, y = mean_arm_expr, 
        colour = group),
    linewidth = .8, linetype = "11") +
  scale_colour_manual(
    values = c(manual_col, "Global mean" = "black"), breaks = legend_order) +
    scale_x_continuous(breaks =hg38_chrom_info$cum_chromosome_mid , labels = hg38_chrom_info$chrom, expand = c(0,0)) +
  theme_classic() +
  theme(axis.text.x=element_text(colour="black", size=8)) +
  theme(axis.text.x = element_text(angle = 50, hjust = 1)) +
  theme(axis.text.y=element_text(colour="black", size=9)) +
  theme(axis.title.x=element_text(colour="black", size=8)) +
  theme(axis.title.y=element_text(colour="black", size=8)) +
  theme(legend.text=element_text(colour="black", size=8)) +
  ylim(0,1) +
  theme(legend.position="right") +
  theme(legend.title = element_blank())+
  ylab("Log-normalised expression") +
  xlab("Chromosome") +
  ggtitle("Cell type arm means")
