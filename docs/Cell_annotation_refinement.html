Cell annotation refinement

Cell annotation refinement

Here, the cell type annotations generated using the 10x Genomics label transfer workflow were further refined (https://www.10xgenomics.com/analysis-guides/xenium-cell-type-annotation).

In particular, the Ciliated Epithelial Cells population was re-evaluated because a substantial proportion of these cells were located outside the histologically normal fallopian tube epithelium.

In addition, Secretory Epithelial Cells were identified within the Fallopian Tube Epithelium population and annotated as a separate cell type.

Subclusters

Ciliated Epithelial Cells were subclustered to determine whether distinct populations could explain the observed separation between cells located within and outside the histologically normal fallopian tube region.

# Recompute UMAP on subset to identify subpopulations
# Subset object
cilia_obj <- subset(xenium.obj, subset = cell_type == "Ciliated Epithelial Cells")

DefaultAssay(cilia_obj) <- "Xenium"

cilia_obj <- cilia_obj %>%
  NormalizeData() %>%
  FindVariableFeatures() %>%
  ScaleData() %>%
  RunPCA(npcs = 20) %>%

Cell type enrichment analysis

To further characterise the identified ciliated epithelial subclusters, marker genes from each cluster were analysed using Enrichr against the CellMarker and PanglaoDB reference databases. These databases were used to determine whether either cluster was enriched for annotated ciliated epithelial cell signatures or alternative cell states.

# Cluster specific markers for enrichr
Idents(cilia_obj) <- "seurat_clusters"
all_markers <- FindAllMarkers(
  cilia_obj,
  only.pos = TRUE,

Summary

The initial cell type annotations generated using the 10x Genomics label transfer workflow were refined.

Ciliated Epithelial Cells segregated into two distinct subpopulations. One population localised predominantly within the histologically normal fallopian tube epithelium and retained a canonical ciliated epithelial transcriptional profile.. The second population was enriched outside the normal fallopian tube region and was therefore reannotated as Tumour Associated Ciliated Epithelial Cells.

In addition, Secretory Epithelial Cells were identified within the Fallopian Tube Epithelium population using PAX8 expression and annotated as a separate cell type.

The refined annotations generated here were used in all downstream analyses.
